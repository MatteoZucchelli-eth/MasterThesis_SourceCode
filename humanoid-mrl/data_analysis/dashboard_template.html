Dataset preflight

Overview and integrity checks for LeRobot datasets. PCA coverage and the repeated-action fraction are descriptive heuristics—not predictions of policy success.

Overview

Integrity

These checks identify data that may fail to load or silently corrupt training.

PCA target coverage

One dot per episode, projected from 3-D onto the two directions of greatest target variation. Grid spacing equals the target width. Coordinates are centered PCA coordinates, not literal wall axes.

Metrics

Interpretation

Episodes / PCA target cell
The 5th–95th percentile PCA rectangle divided into target-sized cells, then episode count divided by cell count. Useful for comparing spatial sampling; it has no universal pass threshold.
Goal nearest-neighbour distance
Median distance from each target to its nearest target from the same task. Lower values indicate denser local sampling.
Demo target-hit fraction
Fraction of labelled episodes whose minimum target distance is within half the supplied target width.
Repeated-action fraction
Median episode fraction of consecutive action vectors that are exactly identical. This exposes zero-order-hold command streams but is not automatically an error.
